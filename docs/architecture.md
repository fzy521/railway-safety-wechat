# 系统架构文档

## 概述

梁邹铁路专用线运营安全监控系统是一个基于Web的铁路安全管理系统，采用前后端分离架构，支持多种部署模式。

## 技术架构

### 前端架构
- **技术栈**：HTML5 + CSS3 + JavaScript (ES6+)
- **UI框架**：Tailwind CSS
- **图表库**：ECharts.js
- **动画库**：Anime.js
- **特点**：纯前端实现，无构建工具依赖

### 后端架构
- **运行时**：Node.js (≥16.0.0)
- **Web框架**：Express.js 4.18.2
- **数据库**：SQLite 3（轻量级，无需独立服务器）
- **认证**：JWT (jsonwebtoken)
- **安全**：Helmet, CORS, Rate Limiting
- **日志**：Winston

### 部署架构
系统支持四种部署模式：

1. **演示模式** (`--demo`)
   - 纯前端运行
   - 使用内存模拟数据
   - 无需数据库
   - 适合快速演示

2. **完整模式** (默认)
   - 前后端完整部署
   - SQLite数据库
   - 生产环境推荐

3. **简单模式** (`--simple`)
   - 简化后端配置
   - 快速开发测试

4. **原生模式** (`--native`)
   - 零依赖运行
   - 纯Node.js实现

## 数据流架构

### 前端数据流
```
用户操作 → 事件处理 → API调用 → 数据更新 → UI渲染
```

### 后端数据流
```
请求接收 → 路由分发 → 中间件处理 → 业务逻辑 → 数据库操作 → 响应返回
```

### 数据库架构
- **用户管理**：用户、角色、权限
- **安全管理**：检查、隐患、事故
- **培训管理**：课程、记录、证书
- **设备管理**：设备、维护记录
- **系统管理**：配置、日志

## 安全架构

### 认证授权
- **JWT Token**：无状态认证
- **角色权限**：基于角色的访问控制
- **会话管理**：支持持久化会话

### 数据安全
- **密码加密**：bcrypt哈希
- **输入验证**：Joi验证库
- **SQL注入防护**：参数化查询
- **XSS防护**：Helmet中间件

### 网络安全
- **CORS**：跨域请求控制
- **Rate Limiting**：请求频率限制
- **Security Headers**：安全响应头

## 技术选型理由

### 选择SQLite的原因
1. **零配置**：无需安装和配置
2. **轻量级**：适合中小型应用
3. **可靠性**：ACID事务支持
4. **性能**：读写速度优秀
5. **可移植**：单文件数据库

### 选择Express的原因
1. **简洁灵活**：轻量级Web框架
2. **生态丰富**：大量中间件可用
3. **学习成本低**：API简单直观
4. **性能优秀**：处理能力强

### 选择纯前端方案的原因
1. **快速开发**：无需构建工具
2. **易于部署**：静态文件即可运行
3. **技术门槛低**：HTML/CSS/JS基础
4. **兼容性好**：支持所有现代浏览器
