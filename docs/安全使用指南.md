# 铁路安全监控系统 - 安全使用指南

## 0. 安全管理专家智能体职责划分

### 0.1 子职责划分
安全管理专家智能体细分为两个子职责：

#### 0.1.1 安全合规审查
- **核心职责**：确保系统符合GBT 33000-2025《企业安全生产标准化基本规范》要求，审查系统设计和实现的合规性，评估安全管理制度的有效性，监督合规性要求的执行情况，提供合规性改进建议。

#### 0.1.2 风险评估
- **核心职责**：识别系统中的安全风险，评估风险的严重程度和可能性，制定风险管控措施，监控风险变化情况，提供风险管控改进建议。

### 0.2 协作机制
- **内部协作**：安全合规审查为风险评估提供合规性要求和限制，风险评估为安全合规审查提供风险管控措施的合规性验证需求。
- **外部协作**：与项目协调智能体、Web后台开发智能体、小程序开发智能体、云开发智能体、数据可视化智能体等协作，提供安全管理支持。

## 3. 安全风险分级管控

### 3.1 风险辨识

#### 3.1.1 辨识范围
系统覆盖以下风险辨识范围：
- **人员**：作业人员能力、安全意识、防护装备使用等
- **设备**：铁路机车、信号设备、轨道设施、通信系统等
- **环境**：自然环境（天气、地质）、作业环境（照明、通风、温度）等
- **管理**：安全制度、操作规程、培训教育、应急管理等
- **作业**：接发列车、调车作业、设备检修、施工作业等

#### 3.1.2 辨识方法
系统支持以下风险辨识方法：
- **头脑风暴法**：组织相关人员集体讨论识别风险
- **经验判断法**：基于历史事故和经验识别风险
- **工作危害分析法（JHA）**：对作业活动进行分解分析风险
- **安全检查表法（SCL）**：根据标准规范制定检查表识别风险
- **风险矩阵法**：结合风险发生可能性和后果识别风险

#### 3.1.3 辨识流程
1. **确定辨识范围**：明确需要辨识的作业区域和活动
2. **组建辨识小组**：由安全管理人员、技术人员、作业人员组成
3. **收集基础资料**：了解设备、工艺、环境等信息
4. **实施风险辨识**：采用适当方法识别潜在风险
5. **记录风险信息**：将辨识结果录入系统
6. **审核确认**：由安全管理员审核确认辨识结果

### 3.2 风险评估

#### 3.2.1 MES法风险评估
系统采用 M(控制措施状态) × E(暴露频次) × S(事故后果) 方法评估风险：
- **M值**：0-2（无控制、部分控制、有效控制）
- **E值**：0-5（暴露频率）
- **S值**：0-5（事故后果严重程度）
- **风险值R** = M × E × S

#### 3.2.2 风险等级判定
- 红色：重大风险（R ≥ 15）
- 橙色：较大风险（8 ≤ R < 15）
- 黄色：一般风险（3 ≤ R < 8）
- 蓝色：低风险（R < 3）

### 3.3 风险管控操作

#### 3.3.1 添加风险点

## 4. 隐患排查治理

### 4.1 隐患登记

#### 4.1.1 现场隐患报告
1. 在小程序端点击"隐患报告"
2. 填写隐患基本信息
3. 上传现场照片
4. 选择隐患类型和等级
5. 提交报告

#### 4.1.2 隐患分级
- **重大隐患**：可能导致严重事故的隐患
- **较大隐患**：可能导致较大事故的隐患
- **一般隐患**：可能导致一般事故的隐患
- **轻微隐患**：对安全生产影响较小的隐患

### 4.2 整改流程

#### 4.2.1 整改任务分配
1. 安全管理员接收隐患信息
2. 分析隐患原因
3. 制定整改方案
4. 分配整改责任人
5. 设置整改期限

#### 4.2.2 整改进展跟踪
1. 整改责任人登录系统
2. 更新整改进展
3. 上传整改照片
4. 记录整改措施
5. 提交整改结果

### 4.3 验收销号

#### 4.3.1 整改验证
1. 安全管理员审核整改结果
2. 进行现场验收
3. 确认整改完成
4. 点击"验收通过"
5. 隐患销号

## 5. 隐患督办机制

### 5.1 挂牌督办

#### 5.1.1 督办对象
- 重大隐患
- 超期未整改隐患
- 反复出现的隐患

#### 5.1.2 督办流程
1. 系统自动识别需督办隐患
2. 安全管理员确认挂牌
3. 设置督办级别（部门级/公司级）
4. 添加督办责任人
5. 启动督办

### 5.2 督办跟踪
- 查看督办列表
- 跟踪督办进展
- 发送提醒通知
- 记录督办结果
- 督办结案

## 6. 日常巡检管理

### 6.1 巡检类型
- **日常巡检**：每日/每班例行检查
- **定期巡检**：每月/每季全面检查
- **专项巡检**：针对特定风险的检查

### 6.2 智能检查表
- 系统根据风险自动生成
- 包含检查项和标准
- 异常情况记录
- 整改建议

### 6.3 巡检记录
- 填写巡检内容
- 上传检查照片
- 记录发现问题
- 提交巡检报告
