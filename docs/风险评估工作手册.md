# 风险评估工作手册

## 1. 手册概述

### 1.1 目的
本手册旨在规范风险评估子职责的工作流程、标准和要求，确保铁路安全监控系统的风险评估工作符合GBT 33000-2025《企业安全生产标准化基本规范》及相关法律法规要求。

### 1.2 适用范围
本手册适用于安全管理专家智能体的风险评估子职责，包括对铁路安全监控系统中各类风险的辨识、分析、评价和管控。

### 1.3 职责定义
风险评估子职责负责：
- 风险辨识范围和方法确定
- 风险评估模型设计和优化
- 风险等级判定标准制定
- 风险管控措施制定和评估
- 风险监控和预警机制建立
- 风险评估报告生成
- 风险管控效果评价

## 2. 风险辨识

### 2.1 辨识范围
1. **设备设施风险**：铁路运输设备、信号系统、供电系统、通信系统等
2. **作业环境风险**：温度、湿度、照明、噪声、振动等
3. **作业活动风险**：调车作业、维修作业、巡检作业等
4. **人员风险**：人员操作失误、安全意识不足等
5. **管理风险**：安全管理制度不完善、培训不到位等
6. **环境风险**：自然灾害、恶劣天气等

### 2.2 辨识方法
1. **现场观察法**：通过观察设备运行状态和人员操作行为识别风险
2. **检查表法**：根据经验和标准制定检查表，逐项检查识别风险
3. **头脑风暴法**：组织相关人员进行头脑风暴，识别潜在风险
4. **故障树分析**：通过分析事故发生的原因识别风险
5. **事件树分析**：通过分析事件发展的可能性识别风险
6. **预先危险性分析**：在系统设计阶段识别潜在风险

### 2.3 辨识流程
1. 确定辨识范围和目标
2. 选择合适的辨识方法
3. 收集相关资料和信息
4. 组织辨识团队，明确分工
5. 实施风险辨识
6. 记录辨识结果
7. 整理和分类风险信息

## 3. 风险评估模型

### 3.1 MES风险评估方法
铁路安全监控系统采用MES法进行风险评估，该方法符合GBT 33000-2025《企业安全生产标准化基本规范》的要求。

#### 3.1.1 参数定义
- **M (控制措施的状态)**：
  - 5: 无控制措施
  - 3: 有减轻后果的应急措施，包括警报系统、个体防护用品等
  - 1: 有预防措施、控制文件，如机电防护装置，但须保证有效

- **E1 (人员暴露于危险环境的频繁程度)**：
  - 10: 连续暴露
  - 6: 每天工作时间内暴露
  - 3: 每周一次，或偶然暴露
  - 2: 每月一次暴露
  - 1: 每年几次暴露
  - 0.5: 更少地暴露

- **E2 (危险状态出现的频次)**：
  - 10: 常态
  - 6: 每天工作时间出现
  - 3: 每周一次或偶尔出现
  - 2: 每月一次出现
  - 1: 每年几次出现
  - 0.5: 更少地出现

- **S (事故的可能后果)**：
  - 10: 有多人死亡 / ＞1000万 / 有重大环境影响的不可控排放
  - 8: 有1人死亡或多人永久失能 / 100万-1000万 / 有中等环境影响的不可控排放
  - 4: 永久失能（1人）/ 10万-100万 / 有较轻环境影响的不可控排放
  - 2: 需医院治理，缺工 / 1万-10万 / 有局部环境影响的可控排放
  - 1: 轻微，仅需急救 / ＜1万 / 无环境影响

#### 3.1.2 风险值计算
风险值 R = M × max(E1, E2) × S

#### 3.1.3 风险等级判定
根据风险值的大小，将风险分为四个等级，符合GBT 33000-2025第7.2.3条的红橙黄蓝四色分级要求：
- **重大风险（红色）**：R > 180
- **较大风险（橙色）**：90 ≤ R ≤ 180
- **一般风险（黄色）**：40 ≤ R < 90
- **低风险（蓝色）**：R < 40

### 3.2 评估流程
1. 收集风险辨识结果
2. 确定评估参数（M、E1、E2、S）
3. 计算风险值
4. 判定风险等级
5. 记录评估结果
6. 生成评估报告

## 4. 风险管控

### 4.1 管控原则
1. **分级管控**：根据风险等级采取不同的管控措施
2. **源头管控**：从风险产生的根源入手，采取预防措施
3. **系统管控**：采用系统的方法，全面管控各类风险
4. **动态管控**：定期评估风险变化，及时调整管控措施

### 4.2 管控措施
根据风险等级的不同，采取相应的管控措施：

#### 4.2.1 重大风险（红色）管控措施
- 立即整改，落实管控措施
- 公司级监督，定期检查
- 制定专项应急预案
- 加强人员培训和教育
- 必要时停止相关作业活动

#### 4.2.2 较大风险（橙色）管控措施
- 强化管控措施，部门级监督
- 制定整改方案，明确责任人和时间节点
- 定期检查管控措施的有效性
- 加强人员培训和教育

#### 4.2.3 一般风险（黄色）管控措施
- 制定管控方案，班组级监督
- 落实管控责任，定期检查
- 加强日常管理和维护

#### 4.2.4 低风险（蓝色）管控措施
- 常规监控，定期复核
- 加强日常管理和维护
- 必要时采取改进措施

### 4.3 管控流程
1. 根据风险等级制定管控措施
2. 明确管控责任人和时间节点
3. 实施管控措施
4. 定期检查管控措施的有效性
5. 评估管控效果
6. 调整管控措施（如有必要）

## 5. 风险监控与预警

### 5.1 监控内容
1. 风险等级变化情况
2. 管控措施的有效性
3. 风险因素的变化情况
4. 事故隐患的发生情况

### 5.2 监控方法
1. **日常检查**：定期对设备设施、作业环境、作业活动等进行检查
2. **专项检查**：针对特定风险进行专项检查
3. **在线监控**：通过系统实时监控设备运行状态和环境参数
4. **数据分析**：对风险相关数据进行分析，识别风险变化趋势

### 5.3 预警机制
1. **预警等级**：与风险等级相对应，分为红色、橙色、黄色、蓝色四级预警
2. **预警触发条件**：
   - 风险等级升级
   - 管控措施失效
   - 风险因素异常变化
   - 发生事故隐患
3. **预警响应**：
   - 红色预警：立即启动应急预案，采取紧急措施
   - 橙色预警：部门级响应，加强监控和检查
   - 黄色预警：班组级响应，采取整改措施
   - 蓝色预警：日常监控，关注变化趋势

## 6. 风险评估报告

### 6.1 报告内容
1. 评估目的和范围
2. 评估方法和标准
3. 风险辨识结果
4. 风险评估结果
5. 管控措施建议
6. 结论和建议

### 6.2 报告格式
1. **封面**：报告名称、评估单位、评估日期
2. **目录**：报告章节和页码
3. **正文**：按照报告内容要求编写
4. **附录**：相关数据、图表、照片等

### 6.3 报告审批
1. 风险评估报告由安全管理专家智能体编制
2. 报告需经项目协调智能体审核
3. 审核通过后，报告提交给相关部门和管理层

## 7. 风险管控效果评价

### 7.1 评价内容
1. 管控措施的实施情况
2. 管控措施的有效性
3. 风险等级的变化情况
4. 事故隐患的发生情况

### 7.2 评价方法
1. **现场检查**：检查管控措施的实施情况
2. **数据分析**：分析风险相关数据，评估管控效果
3. **效果对比**：对比评价前后的风险等级和事故隐患情况

### 7.3 评价流程
1. 制定评价计划，明确评价范围和方法
2. 收集评价所需资料和数据
3. 实施评价
4. 分析评价结果
5. 提出改进建议
6. 生成评价报告

### 9.3 术语定义
- **风险**：发生危险事件或有害暴露的可能性，与随之引发的人身伤害或健康损害的严重性的组合
- **风险评估**：对危险源导致的风险进行分析、评价和分级，对现有控制措施的充分性加以考虑，以及对风险是否可接受予以确定的过程
- **风险管控**：为消除或降低风险而采取的措施
- **MES法**：通过管理措施状态(M)、暴露频率(E)和事故后果(S)进行风险评估的方法
- **双重预防机制**：风险分级管控和隐患排查治理的双重预防机制
