## 修复事故管理页面云函数调用错误

**问题分析**：
- 事故管理页面的 `[INVALID_PARAM] function name not string` 错误是由于云函数调用格式不正确导致的
- `callCloudFunction` 函数期望两个独立参数：`name`（字符串）和 `data`（对象）
- 但代码中使用了对象包装的方式调用，导致 `name` 参数被识别为对象而非字符串

**修复计划**：

1. **修复 `loadIncidentList` 函数**（第391-399行）
   - 将对象包装调用改为独立参数调用
   - 修复前：`callCloudFunction({ name: 'incident-management', data: {...} })`
   - 修复后：`callCloudFunction('incident-management', {...})`

2. **修复 `handleDelete` 函数**（第502-508行）
   - 将对象包装调用改为独立参数调用
   - 修复前：`callCloudFunction({ name: 'incident-management', data: {...} })`
   - 修复后：`callCloudFunction('incident-management', {...})`

3. **修复 `handleSubmit` 函数**（第537-540行）
   - 将对象包装调用改为独立参数调用
   - 修复前：`callCloudFunction({ name: 'incident-management', data: params })`
   - 修复后：`callCloudFunction('incident-management', params)`

**预期结果**：
- 事故管理页面不再报 `[INVALID_PARAM] function name not string` 错误
- 云函数调用能够正常执行
- 事故列表、删除和提交功能都能正常工作
