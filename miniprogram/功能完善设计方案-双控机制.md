3. **隐患分类不精细**
   - 未按10类隐患分类（行车安全、人身安全、外部环境等）

4. **统计分析不全面**
   - 缺少闭环率趋势分析

### 3.2 核心功能设计

#### 3.2.1 MES风险评估模块

**评估公式：**
```
风险值 R = M（控制措施状态） × E（暴露频次） × S（事故后果）

风险等级判定：
- R > 180：一级（重大风险，红色）
- 90 ≤ R ≤ 150：二级（较大风险，橙色）
- 40 ≤ R ≤ 80：三级（一般风险，黄色）
- R ≤ 38：四级（低风险，蓝色）
```

**M值对照表：**
| 分数值 | 控制措施状态 |
|--------|--------------|
| 5 | 无控制措施 |
| 3 | 有减轻后果的应急措施 |
| 1 | 有预防措施、控制文件 |

**E值对照表：**
| 分数值 | 人员暴露时间（E1） | 危险状态频次（E2） |
|--------|-------------------|-------------------|
| 10 | 连续暴露 | 常态 |
| 6 | 每天工作时间内暴露 | 每天工作时间出现 |
| 3 | 每周一次，或偶然暴露 | 每周一次或偶尔出现 |
| 2 | 每月一次暴露 | 每月一次出现 |
| 1 | 每年几次暴露 | 每年几次出现 |
| 0.5 | 更少地暴露 | 更少地出现 |

**S值对照表：**
| 分数值 | 伤害后果 | 财产损失 | 环境影响 |
|--------|----------|----------|----------|
| 10 | 有多人死亡 | ＞1000万 | 有重大环境影响的不可控排放 |
| 8 | 1人死亡或多人永久失能 | 100万-1000万 | 有中等环境影响的不可控排放 |
| 4 | 永久失能（1人） | 10万-100万 | 有较轻环境影响的不可控排放 |
| 2 | 需医院治疗，缺工 | 1万-10万 | 有局部环境影响的可控排放 |
| 1 | 轻微，仅需急救 | ＜1万 | 无环境影响 |

**系统自动计算逻辑：**
```javascript
// 伪代码示例
function calculateRiskLevel(m, e1, e2, s) {
  // 取E1和E2的最大值
  const e = Math.max(e1, e2);

  // 计算风险值
  const r = m * e * s;

  // 判定等级
  if (r > 180) return { level: 1, grade: '重大风险', color: '红' };
  if (r >= 90) return { level: 2, grade: '较大风险', color: '橙' };
  if (r >= 40) return { level: 3, grade: '一般风险', color: '黄' };
  return { level: 4, grade: '低风险', color: '蓝' };
}
```

**业务流程设计：**

**重大隐患挂牌督办案流程：**
```
发现重大隐患 → 专题立案 → 制定专项治理方案
      ↓
公司分管安全副总审批 → 安委会挂牌督办
      ↓
明确治理时限（≤3个月）→ 分阶段细化措施
      ↓
督导治理 → 过程跟踪 → 协调解决问题
      ↓
治理完成 → 现场验证 → 效果评价 → 销号
      ↓
"一事一档"管理（全过程资料长期保存）
```

**检查分类：**

|---------|------|--------|----------|----------|
| **日常排查** | 每班/每日 | 岗位/班组 | 日常作业环节、设备设施 | 移动端快速检查 |

**智能检查表生成逻辑：**
```javascript
// 根据风险等级生成检查频次
function getCheckFrequency(riskLevel) {
  switch(riskLevel) {
    case 1: // 重大风险
      return '每周一次';
    case 2: // 较大风险
      return '每月一次';
    case 3: // 一般风险
      return '每季度一次';
    case 4: // 低风险
      return '每半年一次';
  }
}

// 检查项自动填充
function generateChecklist(location, dept) {
  // 获取该部门、该区域的所有风险
  const risks = getRiskByLocationAndDept(location, dept);

  // 转换为检查项
  return risks.map(risk => ({
    checkItem: risk.risk_name,
    checkStandard: risk.control_measures,
    checkMethod: '现场检查/资料核查',
    riskLevel: risk.risk_level,
    frequency: getCheckFrequency(risk.risk_level),
    lastCheckDate: '',
    thisCheckResult: '', // 正常/异常
    abnormalDesc: '',
    handler: ''
  }));
}
```

### 6.1 云函数清单

#### 云函数1: calculateRiskLevel
**功能：** 根据MES值自动计算风险等级
```javascript
// 云函数入口
exports.main = async (event, context) => {
  const { m, e1, e2, s } = event;

  // 计算逻辑
  const e = Math.max(e1, e2);
  const r = m * e * s;

  let level, grade, color;
  if (r > 180) {
    level = 1; grade = '重大风险'; color = '红';
  } else if (r >= 90) {
    level = 2; grade = '较大风险'; color = '橙';
  } else if (r >= 40) {
    level = 3; grade = '一般风险'; color = '黄';
  } else {
    level = 4; grade = '低风险'; color = '蓝';
  }

  // 生成检查频次
  const frequency = getCheckFrequency(level);

  return {
    success: true,
    data: { r, level, grade, color, frequency }
  };
};
```

#### 云函数4: generateMonthlyReport
**功能：** 自动生成月度报表
```javascript
exports.main = async (event, context) => {
  const { year, month } = event;

  // 获取当月隐患数据
  const startDate = new Date(year, month - 1, 1);
  const endDate = new Date(year, month, 1);

  const dangers = await db.collection('hidden_danger_library')
    .where({
      discovery_date: _.gte(startDate).lt(endDate)
    })
    .get();

  // 统计数据
  const stats = {
    total: dangers.data.length,
    major_count: dangers.data.filter(d => d.danger_level === '重大隐患').length,
    closed_count: dangers.data.filter(d => d.status === '已销号').length,
    overdue_count: dangers.data.filter(d => d.is_overdue).length,

    // 按类别统计
    by_category: groupBy(dangers.data, 'danger_category'),

    // 按单位统计
    by_dept: groupBy(dangers.data, 'responsible_dept')
  };

  stats.closure_rate = ((stats.closed_count / stats.total) * 100).toFixed(2);

  return { success: true, data: stats };
};
```
