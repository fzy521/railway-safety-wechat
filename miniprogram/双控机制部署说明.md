# 双控机制功能开发部署说明

## 一、开发进度概览

### ✅ 已完成功能

1. **MES风险评估云函数** (`cloudfunctions/risk-assessment/`)
   - 自动计算风险值 R = M × E × S
   - 自动判定四色等级（红/橙/黄/蓝）
   - 自动生成检查频次
   - 自动设置下次检查日期

2. **重大隐患督办云函数** (`cloudfunctions/danger-supervision/`)
   - 自动识别重大隐患并启动督办
   - 治理进展跟踪
   - 验证申请与效果验收
   - 超期自动检查与提醒

3. **数据库初始化脚本** (`cloud/database/init-db.js`)
   - 自动创建所需集合
   - 创建优化索引
   - 支持测试数据插入

4. **前端API封装** (`utils/double-control-api.js`)
   - MES评估接口
   - 隐患督办全流程接口
   - 统计查询接口
   - 风险公告生成接口

### 3.2 现有页面改造建议

#### 3.2.1 风险登记页面 (pages/risk/risk.js)

**改造点：**
1. 增加MES评估区域
2. 自动计算显示风险等级
3. 显示检查频次和下次检查日期

**代码示例：**
```javascript
// 在表单提交时调用MES评估
async submitRiskForm(formData) {
  wx.showLoading({ title: '评估中...' })

  // 调用MES评估
  const assessResult = await assessRiskLevel({
    m: formData.mValue,
    e1: formData.e1Value,
    e2: formData.e2Value,
    s: formData.sValue
  })

  if (!assessResult.success) {
    wx.hideLoading()
    wx.showToast({
      title: '评估失败',
      icon: 'none'
    })
    return
  }

  // 补充评估结果到表单数据
  const riskData = {
    ...formData,
    rValue: assessResult.data.r,
    riskLevel: assessResult.data.level,
    riskGrade: assessResult.data.grade,
    riskColor: assessResult.data.color,
    checkFrequency: assessResult.data.checkFrequency,
    nextCheckDate: new Date(Date.now() + 180 * 24 * 60 * 60 * 1000)
  }

  // 保存到数据库
  const db = wx.cloud.database()
  await db.collection('risk_library').add({
    data: {
      ...riskData,
      createdAt: new Date(),
      updatedAt: new Date()
    }
  })

  wx.hideLoading()
  wx.showToast({
    title: '保存成功',
    icon: 'success',
    success: () => {
      wx.navigateBack()
    }
  })
}
```

#### 3.2.2 隐患详情页面 (pages/inspection/inspection.js)

**改造点：**
1. 重大隐患显示红色标识
2. 增加督办状态显示
3. 根据状态显示不同操作按钮

**代码示例：**
```javascript
// 在隐患列表中显示督办状态
renderDangerList(dangers) {
  return dangers.map(danger => {
    const isMajor = danger.dangerLevel === '重大隐患'
    const isSupervised = danger.isSupervised

    return {
      ...danger,
      cardClass: isMajor ? 'major-danger-card' : 'normal-danger-card',
      badgeText: isSupervised ? '督办中' : '普通隐患',
      badgeColor: isSupervised ? 'red' : 'blue',
      showSupervisionBtn: isMajor && !isSupervised, // 未启动督办的重大隐患显示启动按钮
      showProgressBtn: isSupervised && danger.status === '整改中',
      showVerifyBtn: danger.status === '待验证'
    }
  })
}

// 启动督办
async handleStartSupervision(dangerId) {
  const result = await startSupervision(dangerId)

  if (result.success) {
    wx.showToast({
      title: '督办已启动',
      icon: 'success'
    })

    // 刷新列表
    this.loadDangerList()
  }
}

// 更新进展
async handleUpdateProgress(dangerId) {
  const { result: progress } = await showProgressInputDialog()

  if (progress) {
    const result = await updateProgress(dangerId, progress, '')

    if (result.success) {
      wx.showToast({ title: '进展已更新' })
      this.loadDangerList()
    }
  }
}

// 验证
async handleVerify(dangerId) {
  const result = await verifyDanger(dangerId, '合格', '安全总监')

  if (result.success) {
    wx.showToast({
      title: '验证通过',
      icon: 'success'
    })
    this.loadDangerList()
  }
}
```
